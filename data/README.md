# Dataset

`healthcare_dataset.csv` contains 55,500 synthetic healthcare records and 15 columns. It
is used only as a realistic tabular workload for sorting algorithms; it does not contain
real patient information.

- Source: [Healthcare Dataset by Prasad Patil on Kaggle](https://www.kaggle.com/datasets/prasad22/healthcare-dataset)
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- Rows: 55,500 (excluding the header)
- SHA-256: `d8c23c7dddaf0e1f5daf26182eb908c219d28a63bb574377c3ba6cb09be8a342`

The dataset is committed so the published benchmark can be reproduced without requiring a
Kaggle account or API token.
